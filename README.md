# The Declaration of the Rights of Man and of the Citizen in Akoma Ntoso

The *Déclaration des Droits de l'Homme et du Citoyen* of August 26, 1789, in Akoma Ntoso XML, with its French text, an English translation, and a CSS stylesheet that sets the 17 articles on twin arched tablets. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `rights-of-man-and-citizen.xml` | The Akoma Ntoso document |
| `rights-of-man-and-citizen.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Document type:** The Declaration is an `<act name="declaration">`, because it remains part of French constitutional law. It is marked as an act here even though the U.S. Declaration of Independence in this archive is a `<statement>`.
- **Structure:** The considerations are a `<recital>` in `<preamble>`, followed by the enacting words in `<formula name="enactingFormula">`. The 17 articles are `<article>` elements in `<body>`, each with its number in `<num>`.
- **English translation:** The translation is a `<doc name="translation">` in an `<attachment>`, with its own metadata. `FRBRtranslation` links it to the French expression, and its article eIds use the same numbers with an `att_english__` prefix.
- **Typography:** Straight apostrophes are set as typographic ones, and French spaces before ";" and ":" are non-breaking.
- **Highlight:** The first sentence of Article 1 is in `<span class="landmark">`. The highlighting is editorial.
- **Jurisdiction:** The URIs use `fr`.

## Sources

- French text: [Présidence de la République](https://www.elysee.fr/la-presidence/la-declaration-des-droits-de-l-homme-et-du-citoyen).
- English translation: the [Avalon Project](https://avalon.law.yale.edu/18th_century/rightsof.asp) at Yale Law School, which does not name the translator. The translation is not official, and it departs from the French in places. Article 1, for example, renders "utilité commune" as "general good".
